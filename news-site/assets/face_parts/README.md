# 顔パーツ画像（キャラクリエイト用・現在は保留中）

個体の顔アイコンを、パーツ単位の画像を組み合わせて生成するための素材置き場。
キャラクリエイト機能自体は一旦非表示にしているが、復活する可能性があるため
ディレクトリだけ先に用意しておく。

## ディレクトリ構成

```
face_parts/
  hair_female/   女性用の髪型
  hair_male/     男性用の髪型
  eyes/          目（男女共通）
  eyebrows/      眉（男女共通）
  mouth/         口（男女共通）
  face_base/     輪郭・肌色のベース（男女共通）
```

## ファイル仕様

- 1024×1024、背景透明のPNG
- 全パーツで顔の基準位置・大きさを揃える（パーツ単体を中央に配置）

## ファイル名の付け方

英語の小文字、単語区切りはアンダースコア、拡張子は`.png`。
ディレクトリ名がカテゴリを表すので、ファイル名はバリエーション名だけでよい。

例：
- `hair_female/bob.png`（ボブ）, `hair_female/ponytail.png`（ポニーテール）
- `hair_male/short.png`（短髪）
- `eyes/droopy.png`（たれ目）, `eyes/round.png`（丸目）
- `mouth/smile.png`
- `face_base/skin_tone_1.png`

同じカテゴリ内でファイル名が重複しないことだけ気をつければ、他は自由。
生成した画像をファイル名だけ整理して送ってもらえれば、該当ディレクトリへの
配置・git管理はこちらで行う。
